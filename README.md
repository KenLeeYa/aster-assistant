# Aster Assistant

A local-first personal assistant foundation. The existing package and protocol names remain `ky-jarvis` for compatibility while the proposed product name is Aster.

This is a **source-visible, proprietary** project under [LICENSE](LICENSE). It is not production ready. It has a FastAPI/LangGraph core, a Next.js/Tauri command center, Android companion source, governed approval and audit paths, and a local Ollama integration. The Windows + WSL2 architecture and optional Colibri gateway are under development. No model, credential, external connector, or privileged tool is enabled by publishing this source.

The current publication candidate excludes local reports, original prompt specifications, user records, generated artifacts, and model files. Read its [publication blockers](PUBLICATION_BLOCKERS.md) before considering a public push. See [Windows + WSL2 foundation](docs/architecture/windows-wsl2-foundation.md), [future-host manifest](docs/operations/future-host-manifest.md), and [publication review](docs/architecture/publication-and-ux.md). Hardware-specific installation and live acceptance tests remain pending for the future host.
